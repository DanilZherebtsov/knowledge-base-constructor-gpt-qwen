# Конструктор LLM-вики — редакции для OpenAI и Qwen

**Идея — LLM-вики.** Источники проекта однократно компилируются в постоянную связанную вику; дальше агент отвечает, читая её, а не выводя одно и то же из сырых документов заново при каждом вопросе.

В репозитории — две редакции одного конструктора. Каждая собирает под конкретную задачу рабочий проект: скелет + выбранные механики + манифест класса (продукт / исследование / ведение дела). Это не шаблон для копирования, а сборка коротким интервью.

| Папка | Для чего | Корневой файл | Машинерия |
|---|---|---|---|
| [`openai-constructor/`](openai-constructor/) | Codex — терминал, плагины к редакторам, локальные проекты в десктопном приложении ChatGPT | `AGENTS.md` | `.codex/` |
| [`qwen-constructor/`](qwen-constructor/) | `qwen-code` — терминал, десктопное приложение, плагины к редакторам | `QWEN.md` | `.qwen/` |

## Как запустить

1. Склонируй репозиторий.
2. **Открой как проект именно нужную папку** — `openai-constructor/` или `qwen-constructor/`, а не корень репозитория. В корне лежат обе редакции, и агент не поймёт, какую брать.
3. Просто начни разговор: конструктор сам предложит настройку и проведёт интервью.
4. **Если настройка не предложилась сама** (среда не подхватила корневой файл), напиши в чат: **`прочитай START-HERE.md и следуй ему`**. Фраза называет файл, поэтому работает даже когда никакие правила проекта не загрузились.

## Прежде чем полагаться на это в бою

Обе редакции получены переносом с конструктора для Claude Code 16.09.2026 и **боем не проверены ни разу**. Перенос делался по документации вендоров; всё, что осталось непроверенным, названо прямо — в `PLATFORM-NOTES.md` каждой редакции, вместе с тем, чего в редакции нет и почему.

Самое важное:

- **OpenAI.** У Codex жёсткий бюджет на размер всех инструкций сразу (по умолчанию 32 KiB, считается вместе с личным `~/.codex/AGENTS.md` человека), и при превышении он отбрасывает хвост **молча** — без ошибки и без отметки в интерфейсе. Корневой файл ужат под этот бюджет, но проверить это нужно первым делом.
- **Qwen.** Инструмент `save_memory` пишет в глобальный `~/.qwen/QWEN.md`, то есть в слой инструкций **выше** вики проекта, — для знания проекта им пользоваться нельзя. И режим `fork` у субагентов наследует контекст родителя, поэтому независимой проверки не даёт, хотя выглядит так, будто даёт.

Оригинальная редакция для Claude Code — [knowledge-base-constructor](https://github.com/DanilZherebtsov/knowledge-base-constructor).
